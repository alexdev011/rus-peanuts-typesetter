# Шрифт выбирается для каждого блока вручную

Раньше тип строки Перевода решал и место, и шрифт: строка с тире — Реплика шрифтом Peanuts by me, без тире — Звук шрифтом MP Manga (по умолчанию Shadow). Разбор 301 PSD команды за 1962–1963 годы (1388 текстовых слоёв) показал, что так команда не верстает. Peanuts by me — 1172 слоя. Сплошной MP Manga — 109 слоёв, и в основном это реплики с нажимом внутри Баблов. Shadow — всего 15. Ещё около 90 слоёв набраны десятком других шрифтов, по-разному от звука к звуку. Поэтому у Текстового блока теперь свой Шрифт (PostScript-имя). Каждый новый блок получает Шрифт реплик, а другой Шрифт выбирают в программе из Набора шрифтов — шрифтов, которые команда сама кладёт в папку `fonts`. Тире по-прежнему решает только, как ставится текст: Реплика переносится по колонке, Звук стоит одной строкой.

## Considered Options

- **Угадывать шрифт по скану**: выбор шрифта на скане не записан, это решение команды. Учиться можно только на прошлых PSD, а там в среднем по 9 примеров на нестандартный шрифт. Отвергнуто.
- **Пометка шрифта в файле Перевода** (`[TroubleSide] ГАВ`): программе просто, но выбирать шрифт пришлось бы переводчику, а не тому, кто верстает, и помнить точные названия. Можно добавить позже поверх ручного выбора.

## Consequences

Проект сохраняется в формате версии 2. Проекты версии 1 открываются: флаг Shadow превращается в Шрифт. В PSD уходит PostScript-имя, поэтому шрифт должен быть установлен в Windows у того, кто открывает PSD.
