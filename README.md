Внутренняя утилита для автоматизации верстки и обработки стрипов Peanuts на русский язык.

Программа убирает рутину: сама находит реплики и звуковые эффекты на скане, аккуратно затирает оригинальный английский текст и расставляет русский перевод из обычного `.txt` файла с правильными шрифтами, переносами и автоподгонкой размера.

---

## Что умеет программа

### 1. Автоматический тайпсеттер стрипов
* **Умная очистка баблов и SFX:** алгоритм сканирует изображение, отделяет буквы от контуров рисунка и стирает их, не трогая рамки кадров и персонажей.
* **Автоматическая расстановка перевода:** достаточно закинуть `.txt` файл. Реплики сами центруются в баблах, а длинные слова автоматически переносятся по слогам (дефисы подставляются по правилам русского языка).
* **Поддержка двух типов шрифтов:**
  * Реплики персонажей — шрифт `Peanuts by me`.
  * Эмоции, выкрики и звуки (`ХАХАХА!`, `ААЙ!`) — шрифт `Mp Manga Bold Shadow` (или обычный `MP Manga Font Bold`).
* **Считывание и ручной изгиб текста:** если оригинальный звук нарисован дугой, программа определяет угол и изгибает русский текст по такой же траектории. Также есть отдельная кнопка для ручной настройки дуги через ползунок.
* **Удобное ручное редактирование:**
  * Перетаскивание блоков мышкой в любое место кадра.
  * Двойной клик по фразе для редактирования текста на лету.
  * Интерактивные маркеры изменения ширины колонки и размера кегля.
  * Точечный ластик по правой кнопке мыши (если на скане осталась помарка или артефакт).
  * Полноценная отмена действий (`Ctrl+Z`).
  * Кнопка быстрого предпросмотра оригинала для сверки с исходником.

### 2. Multi-tool (обработка и нарезка)
Встроенная вкладка на базе движка ImageMagick для пакетной подготовки стрипов:
* Нарезка воскресных и ежедневных выпусков (`Slice`, `Square`).
* Автоматическая датировка файлов по маске `peYYYY-MM-DD`.
* Подгонка размеров под формат Acomics.
* Проверка и валидация уже переведённых дат через чек-лист.

## Формат файла перевода (.txt)

Файл с переводом оформляется максимально просто:

```text
1979-11-19
- ПРИВЕТ, ЧАРЛИ БРАУН!
- КАК ДЕЛА?
ХАХАХА!
- ВСЁ ОТЛИЧНО!
```

* Строка с **тире в начале** (`- текст`) воспринимается как обычная реплика в бабл (шрифт `Peanuts by me`).
* Строка **без тире** (`ХАХАХА!`) воспринимается как выкрик/звук на фоне (шрифт `Mp Manga Bold Shadow`).
* Строки с датами, сноски (`* ...`) и комментарии в скобках программа отфильтровывает сама.

## Установка и запуск

### Требования
* Python 3.10+
* Windows 10/11 (рекомендуется)
* [ImageMagick](https://imagemagick.org/script/download.php#windows) (нужен для работы второй вкладки нарезки)

### Быстрый старт

1. Клонируем репозиторий:
   ```bash
   git clone https://github.com/alexdev011/rus-peanuts-typesetter.git
   cd rus-peanuts-typesetter
   ```

2. Устанавливаем библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

3. Запускаем:
   ```bash
   python comic_typesetter.py
   ```

*(При первом запуске скрипт сам проверит наличие библиотек и ImageMagick и предложит доустановить их при необходимости).*

## Сборка в один .exe файл

Чтобы собрать программу в независимый исполняемый файл без необходимости ставить Python на других машинах:

```bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --add-data "fonts;fonts" comic_typesetter.py
```

Готовый билд появится в папке `dist/comic_typesetter/`.
