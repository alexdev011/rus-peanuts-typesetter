# RUS PEANUTS — Auto-Typesetter & Multi-Tool

![Python Version](https://img.shields.io/badge/python-3.9+-black?style=flat&logo=python)
![PyQt6](https://img.shields.io/badge/GUI-PyQt6-black?style=flat&logo=qt)
![License](https://img.shields.io/badge/license-MIT-black?style=flat)
![Status](https://img.shields.io/badge/release-v1.0-black?style=flat)


Внутренняя утилита для автоматизации верстки и обработки стрипов Peanuts на русский язык.

Программа убирает рутину: сама находит реплики и звуковые эффекты на скане, аккуратно затирает оригинальный английский текст и расставляет русский перевод из обычного `.txt` файла с правильными шрифтами, переносами и автоподгонкой размера.

---

## Что умеет программа

### 1. Автоматический тайпсеттер стрипов
* **Поиск надписей и очистка:** один поиск находит любой английский текст — от мелких реплик до крупных звуков — и по контуру вокруг решает, в бабле он или на рисунке. Логотип PEANUTS, подписи, даты, лица и трава не считаются надписями. Найденный текст стирается, рамки кадров и персонажи остаются.
* **Автоматическая расстановка перевода:** достаточно закинуть `.txt` файл. Реплики сами центруются в баблах, а длинные слова автоматически переносятся по слогам (дефисы подставляются по правилам русского языка).
* **Любые шрифты:** всё ставится шрифтом `Peanuts by me`, а для любого текста можно выбрать другой шрифт в списке на панели. Свои шрифты добавляются через меню «Шрифты → Добавить шрифты…» (или перетаскиванием файла `.ttf`/`.otf` в окно) — они копируются в папку `fonts` и остаются после перезапуска. В списке шрифт называется так же, как его файл.
* **Считывание и ручной изгиб текста:** если оригинальный звук нарисован дугой, программа определяет угол и изгибает русский текст по такой же траектории. Также есть отдельная кнопка для ручной настройки дуги через ползунок.
* **Удобное ручное редактирование:**
  * Перетаскивание блоков мышкой в любое место кадра.
  * Двойной клик по фразе для редактирования текста на лету.
  * Интерактивные маркеры изменения ширины колонки и размера кегля.
  * Карандаш: закрасить стрип белым или чёрным нужной толщины (если на скане осталась помарка или надо дорисовать штрих). Вернуться к выделению текста — кнопка «Курсор» или Esc. Правая кнопка мыши стирает белым и без Карандаша. Работа Карандашом сохраняется, даже если загрузить другой перевод.
  * Полноценная отмена действий (`Ctrl+Z`).
  * Кнопка быстрого предпросмотра оригинала для сверки с исходником.
* **Пачка — папка стрипов за раз:** «1. Стрип → Папка…» (или перетащить папку в окно) открывает все стрипы папки, а один файл перевода раздаёт им Переводы по датам в именах файлов (`pe1963-04-08.png` ↔ `1963-04-08`). Слева список стрипов (● — есть несохранённые правки, ✓ — сохранён, «? нет перевода»), переход — стрелками или Ctrl+PgUp/PgDown. Правки каждого стрипа помнятся, пока программа открыта; «Файл → Сохранить всю Пачку» кладёт PNG и проект каждого стрипа в выбранную папку (по умолчанию `result`, см. ниже). Стрипы без даты в имени сначала нужно датировать в Multi tool.
* **Сохранение (меню «Файл»):** всё сохраняется в папку `result` рядом с программой, туда же пишет Multi tool. Окно сохранения сразу открывается в ней с готовым именем файла: достаточно нажать Enter. Если нужно, можно выбрать другую папку.
  * **PNG** — готовый стрип.
  * **Проект** (`.rpeanuts`, `Ctrl+S`) — вёрстка со всеми правками: открываешь позже и правишь дальше прямо в программе.
  * **Экспорт в PSD** — файл для Фотошопа с настоящими текстовыми слоями (текст можно перепечатать). PSD собирает сам Фотошоп: программа запускает его и передаёт сценарий. Слои: «Фон» (очищенный стрип), скрытый «Оригинал» и по слою на каждую реплику и звук. Изгиб становится деформацией «Дуга», жирность — обводкой слоя: близко к программе, но не пиксель в пиксель. Если Фотошоп не ответил, программа покажет путь к сценарию — его можно запустить вручную через «Файл → Сценарии → Обзор».

### 2. Multi-tool (обработка и нарезка)
Встроенная вкладка для пакетной подготовки стрипов:
* Нарезка воскресных и ежедневных выпусков (`Slice`, `Square`).
* Автоматическая датировка файлов по маске `peYYYY-MM-DD`.
* Подгонка размеров под формат Acomics.
* Проверка и валидация уже переведённых дат через чек-лист.

## Формат файла перевода (.txt)

Файл с переводом оформляется максимально просто:

```text
1963-04-08
- ПРИВЕТ, ЧАРЛИ БРАУН!
-КАК ДЕЛА?
-  ВСЁ ОТЛИЧНО!
Звуки:
- БАЦ!

1963-04-09
- ПОКА!
```

* В одном файле можно держать переводы многих стрипов: каждый начинается со строки с датой `YYYY-MM-DD` (что после даты в этой строке — не важно). Стрип берёт перевод своей даты. Файл без дат — это перевод одного стрипа.

* У каждой строки **тире в начале**; пробелы вокруг тире не важны.
* Сначала все **реплики** в порядке чтения: они встают в баблы по порядку и переносятся по слогам.
* Потом строка **`Звуки:`** (регистр и двоеточие не важны) и все **звуки** в порядке чтения: они встают на найденные звуки на рисунке, крупно, в одну строку. Звук стирается с рисунка, только когда на него встала строка перевода.
* Старые файлы без `Звуки:` тоже читаются: звуками считаются строки без тире в самом конце.
* Шрифт в файле не указывается: его выбирают в программе.
* Строки с датами, сноски (`* ...`) и комментарии в скобках программа отфильтровывает сама.

## Структура проекта

```text
├── comic_typesetter.py        # Точка входа (запуск и сборка .exe)
├── rus_peanuts/
│   ├── typesetting/           # Вёрстка: анализ стрипа, Документ, раскладка текста, шрифты
│   ├── publishing/            # Multi tool: Нарезка, Квадрат, Датировка (numpy/Pillow)
│   ├── ui/                    # Окно на Qt: PyQt6 (или PyQt5 для Windows 8.1) через qtpy
│   ├── app.py                 # Запуск приложения
│   └── bootstrap.py           # Проверка зависимостей
├── fonts/                     # Набор шрифтов: сюда же копируются добавленные шрифты
│   ├── Peanuts_by_me.ttf      #   (в git только эти три, остальные — в .gitignore)
│   ├── MPMangaFont-Bold.ttf
│   └── Mp Manga Bold Shadow.ttf
├── tests/                     # Тесты (pytest), см. tests/conftest.py
├── docs/adr/                  # Архитектурные решения
├── GLOSSARY.md                # Словарь терминов проекта
├── requirements.txt           # Зависимости
├── requirements-legacy.txt    # Зависимости сборки для Windows 8.1
└── requirements-dev.txt       # Зависимости для тестов
```

## Установка и запуск

### Требования
* Python 3.10+
* Windows 10/11 (для Windows 8.1 есть отдельная сборка, см. ниже)
* Для экспорта в PSD: Adobe Photoshop CC 2019 или новее, и все шрифты, которыми набран стрип, должны быть **установлены в Windows** — Фотошоп берёт шрифты из системы, а не из папки программы (если шрифта нет, Фотошоп подставит свой и программа об этом предупредит)

### Быстрый старт

1. Клонируем репозиторий:
   ```bash
   git clone https://github.com/alexdev011/rus-peanuts-typesetter.git
   cd rus-peanuts-typesetter
   ```

2. Устанавливаем библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

3. Запускаем:
   ```bash
   python comic_typesetter.py
   ```

*(При первом запуске скрипт сам проверит наличие библиотек и предложит доустановить их при необходимости).*

## Сборка в один .exe файл

Чтобы собрать программу в независимый исполняемый файл без необходимости ставить Python на других машинах:

```bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --add-data "fonts;fonts" comic_typesetter.py
```

Готовый билд появится в папке `dist/comic_typesetter/`.

Такой .exe работает только на **Windows 10 и 11**: Qt 6 и Python 3.13 вызывают функции Windows, которых нет в старых версиях, и упаковка в .exe этого не меняет.

### Сборка для Windows 8.1

Для старых машин программа собирается на **Qt 5** (PyQt5 5.15 — последняя Qt, которая поддерживает Windows 8.1) и **Python 3.10**. Код один и тот же: окно написано через прослойку [qtpy](https://github.com/spyder-ide/qtpy), которая берёт ту Qt, что установлена. Окружение нужно отдельное, чтобы в нём не было PyQt6:

```bat
py -3.10 -m venv venv-legacy
venv-legacy\Scripts\pip install -r requirements-legacy.txt
venv-legacy\Scripts\pyinstaller --noconfirm --onedir --windowed --add-data "fonts;fonts" --name comic_typesetter_win81 --workpath build\win81 comic_typesetter.py
```

Билд появится в `dist/comic_typesetter_win81/`, отдавать нужно всю папку. Что стоит знать:

* Нужна именно **8.1** со всеми обновлениями. На Windows 8 без обновления до 8.1 Python 3.10 не запустится.
* Если при запуске пишет, что нет `api-ms-win-crt-runtime-l1-1-0.dll`, на машину надо поставить [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist) (x64) или обновление KB2999226.
* Сборка 64-битная. Для 32-битной Windows нужен 32-битный Python 3.10.
* Шрифты на Qt 5 измеряются через GDI, а на Qt 6 через DirectWrite. GDI округляет высоту строки до пикселя, поэтому автоподбор местами ставит кегль на 1–1,5 пт меньше, чем обычная сборка. Проекты и PSD при этом совместимы между сборками.
* Тесты в этом окружении: `venv-legacy\Scripts\pip install pytest psd-tools`, потом `venv-legacy\Scripts\python -m pytest`. Точные эталоны вёрстки записаны на Qt 6, поэтому на Qt 5 они пропускаются.
